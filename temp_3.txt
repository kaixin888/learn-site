## **选品重要因素【毛利】** 

一， 毛利计算 

进行新类目新市场、我第一时间会看类目评论销量、然后就来计算产品毛利、这一步是非常重要的、有相对客观毛利才有机会赚钱 

我是这样计算产品毛利、请看公式： 毛利 = 正常售价 - （产品成本 + 产品头程 + F B A 配送费 + 亚马逊佣金） 以 3 C 苹果手机钢化膜类目来分析 


【正常售价】 

正常售价顾名思义、就是这条链接排名稳定之后、正常的售价我们上架新品的时候、价格是有变动的、有些卖家喜欢用低价策略、然后前期做销量做排名后期再提价、我们推新链接的时候、 就要模拟链接【正常售价】、模拟链接盈亏平衡 

产品成本产品头程、 F B A 配送费亚马逊佣金、这四个成本很容易计算出来 

广告花费和退货费用、这两个费用占比很高的、而且还没有准确的数据、但是对于【毛利】、我们可以相对准确计算出来、还没有出去广告费和退货费的、可以用毛利来扣除、所以毛利也会有负毛利和正毛利

一款产品设定不同的售价、产品毛利也会变动、如何定价也是做运营一种学问、对于有资源有实力的卖家、定价会偏高、因为有实力可以把类目排名卡住 

## 二， 毛利率分析 

毛利率是选品很重要的维度、单单从毛利是不够支撑去选品、比如高客单价产品、定价 1 0 0 美金、毛利有 3 0 美金、毛利数据是挺可观的、但是毛利率就不客观了、因为毛利率仅仅只有 3 0 % 、 比如老铁们看看我做这张表格数据 


但我计算出毛利和毛利率、就会更加清楚这款产品盈亏力度、我们还要看一个成本 

【国内成本】 

对于小卖家来说、工厂和物流是没有账期的、当小卖家把产品发到亚马逊仓库前、就要结算产品成本和物流成本、不管亚马逊发过去的货赚不赚钱、这笔钱你是一定提前结算 

比如我拿一个数据来分析、但这款产品正常售价为了 6 美金、毛利是 1 . 6 2 美金、毛利率只要 2 7 . 0 0 % 、产品成本和物流成本就要 1 . 2 美金、在没有扣广告成本和退货成本、我也只能赚 1 . 6 2 美金、如果计算广告成本和退货成本、不但没办法赚钱还会亏一笔钱、通俗来说 

我们把货发到亚马逊、然后把货卖完了、不但没有回款还要扣信用卡的钱、意思就是、我们把产品成本和物流成本亏了、还把信用卡的钱也亏了、投入的人工成本也亏了、【这种类目这种产品你敢做么？】 

正常来说、毛利是（产品成本 + 物流成本） 3 倍以上、你去做这种类目才有机会赚钱、可能你不一定赚钱、起码产品成本和物流成本、你大概率收回来基本成本 


## 三， C P C 占比分析 

知道毛利和毛利率还不行、我们还要调研一个数据 【 C P C 占比】、什么是 C P C 占比？、 C P C 占比 = 单次竞价 / 毛利 

这个数据很重要、假如这个类目广告单次竞价很高、哪怕产品毛利空间比较高、都有可能大部分毛利给广告费用吃光 

首先我们通过关键词调研工具、调研关键词单次竞价是多少、按照这个 C P C 单价竞价、我们是否有机会赚到钱、比如我调研苹果手机钢化膜、其中一个大词 C P C 大概竞价 【 i p h o n e 1 2 s c r e e n p r o t e c t o r 】 


这个调研数据不一定很精准、起码我大概可以判断出、这个关键词平均单次竞价为 2 美金、一次点击就要收费 2 美金、而且不一定能够出广告订单、把广告转化率做到 2 0 % 就很不错了、这句话的意思、点击 5 次成交一单广告订单、一共花费了 1 0 美金广告费、新链接做到广告转化率 1 0 % 也不错、点击 1 0 次成交一单广告订单、一共花费 2 0 美金广告费用、看看我做的表格数据图片、 就会明白我为什么重视 C P C 占比 


再看看这张图片、钢化膜毛利只要 3 . 3 6 美金、 C P C 单次竞价就要 2 美金点击一次、有可能点击 5 次才成交一单广告单、 2 美金 × 5 次点击等于 1 0 美金、意味着出这单广告单我还要倒贴 1 0 - 3 . 3 6 = 6 . 6 4 美金 

通过模拟其他的单次竞价、、只要把 C P C 单次竞价、控制在 1 美金以内、才有机会少亏钱、但是对于新手卖家来说、太低竞价有没有曝光 

【广告排名 = L i s t i n g 质量得分 * 单次竞价】 不会做 L i s t i n g 质量得分的新手卖家、来做苹果手机钢化膜类目、 等于白送钱给姐夫用 

## 四， 毛利总结
